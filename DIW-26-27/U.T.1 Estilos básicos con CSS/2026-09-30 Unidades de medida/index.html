Unidades de medida

Unidades absolutas

  • Píxel (px)
  • Punto (pt)
  • Centímetro (cm)
  • Milímetro (mm)

Unidades Relativas

vh y vw
Viweport height y Viweport Width. En principio, solo se usan las etiquetas
dvh y dvw
Dynamic Viweport height y Dynamic Viweport width. En principio, solo se usan con la etiqeuta body.
El procentaje (%)
El tamaño cuando usamos el porcentahe se calcula siempre de forma relativa a la etiqueta padre-
Rem
La unidad Root em usa como valor base el tamaño establecido en la pseudoclase : root. Por defecto es 16px, se usa normalmente como caracteres
em
La unidad em usa como valor base el tamaño establecido en la etiqueta padre. Se usa normalmente para caracteres
